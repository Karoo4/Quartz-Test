1. <mark style="background: #FFB8EBA6;">Vectors in a coordinate system :</mark>
- Its easier to work with vectors when we use coordinates $(x,y)$ .
- instead of looking at arrows , we can describe with numbers .
- makes calculations straightforward Example :  (Addition, Subtraction, Magnitude)

2. <mark style="background: #FFB8EBA6;">Standard Position : </mark>
- A vector can be placed anywhere in the plane, but for calculations we prefer to put its <mark style="background: #FFB8EBA6;">tail at the origin</mark> $(0,0)$
- When the tail is at the origin, we call it a <mark style="background: #FFB8EBA6;">standard - position vector.</mark>

3. <mark style="background: #FFB8EBA6;">General case</mark> (When it <mark style="background: #FFB8EBA6;">doesn’t have a origin</mark>) :
- if a vector starts at $(x_{1},y_{1})$ and ends at $(x_{2},y_{2})$ the vector is : $\vec{V} = (x_{2}-x_{1},y_{2}-y_{1})$

#### Example → from $(2,1)$ to (5,4) :
$$\vec{V} = (x_{2}-x_{1} \,,\,y_{2}-y_{1})$$
$$\vec{V} = (5-2\,,\,4-1) = (3,-3)$$

4. <mark style="background: #FFB8EBA6;">Component form:</mark>
#### We can write a vector in component form as:
$$\vec{V} = < x,y>\, \text{or}\, \frac{x}{y}\,\,\text{or}\,\,(x,y)$$
>[!Summary]  
>* Vectors can start anywhere, but often start from the origin.
>* General rule : $\vec{V} = (x_{2}-x_{1} , y_{2}-y_{1})$
>* Notations: $<x,y>$ , $\frac{x}{y}$ , $(x,y)$
>
#### Notations : $<x,y>$ vs $(x,y)$
* $(x,y)$ → Describes a point in the plane.
* $<x,y>$ → Describes a vector in component form.

>[!example] 
>* The point $(3,2)$ means a location at $x=2\,,\,y=2$ .
>* The vector $<3,2>$ means “an arrow” from $(0,0)$ to $(3,2)$.

- When a <mark style="background: #FFB8EBA6;">vector</mark> is written in component form like
$$\vec{V} = < x,y>\, \text{or}\, \frac{x}{y}\,\,\text{or}\,\,(x,y)$$
The <mark style="background: #FFB8EBA6;">scalars</mark> x and y are called the components of $\vec{V}$

- The vector with initial point $(0,0)$ and terminal point $(x,y)$ can be written in component form as
$$\vec{V} = <x,y>$$
* <mark style="background: #FFB8EBA6;">The scalars</mark> $x$ and $y$ are called the components of $\vec{V}$.

## Vector Addition Methods

1. Triangle method: 
		(Tip to tail Rule)
* Place the tail of the second vector at the tip of the first vector.
* Draw the sum as the vector from start of the first to the end of the second.

1. Parallelogram Method: 

* Place both vectors ($v$ and $w$) so they start from the same point.
* Complete the parallelogram using $v$ and $w$ as adjacent sides.
* The diagonal of the parallelogram (from the shared starting point) is the sum ($v+w$ ).

## Properties of vector Addition 

* <mark style="background: #FFB8EBA6;">Commutative :</mark> $v+w = w+v$
* <mark style="background: #FFB8EBA6;">Associative :</mark> $(v+w)+v = v + (w+v)$

>[!summary]
>  * Triangle method: 
> 
>  Put vectors tip to tail, 
>  the diagonal = sum
>  
>  * Parallelogram method:
> 
>  put vectors tail to tail,
>  the diagonal = sum
>  

### Special case : (negative multiplication)
 *  If $k = -1$
$$(-1)\vec{v} = -\vec{v}$$
- This flips the vector to the opposite direction
- magnitude stays the same

>[!note] 
> - Multiplying vector by scalar : (<mark style="background: #FFB8EBA6;">changes size , maybe changes direction.</mark>)
> - Positive Scalar  : (<mark style="background: #FFB8EBA6;">same direction.</mark>)
> - Negative Scalar : (<mark style="background: #FFB8EBA6;">opposite direction.</mark>)
> - Zero Scalar : (<mark style="background: #FFB8EBA6;">Zero Vector.</mark>)

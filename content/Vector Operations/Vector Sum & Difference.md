## Vector Sum : ($\vec{V}+\vec{W}$)

- Vector sum means to add two vectors.
1. Place the tail of $\vec{W}$ at the tip of $\vec{V}$.
2. Draw a new vector from the start of $\vec{V}$ to the end of $\vec{W}$ .
→ The new vector is $\vec{V}+\vec{W}$

## Vector difference : ($\vec{V} - \vec{W}$)
$\vec{V}-\vec{W}$ is defined as $\vec{V} + (-\vec{W})$
→ Where $-\vec{W}$ is the vector $\vec{W}$ flipped to the opposite direction.
→The result called the vector difference.

### Example :
$$\vec{V} = (3,1)$$
$$\vec{W} = (1,3)$$
Find the vector sum ( $\vec{V} + \vec{W}$ ) and vector difference ( $\vec{V} - \vec{W}$) , and find the magnitudes of $\vec{V}+\vec{W}$ and $\vec{V} - \vec{W}$.

1.  **Vector Sum**
$$\vec{V} + \vec{W} = (3,1)\,+\,(1,3) = (3-1\,,\, 1+3) = (4,4)$$
2. **Vector Difference**
$$\vec{V}-\vec{W} = (3,1) + (1,3) = (3-1\,,\,1-3) = (2,2)$$
### Magnitudes
##### For $\vec{V}+\vec{W} = (4,4) :$ 
$$|\vec{V}+\vec{W}| = \sqrt{ 4^2+4^2 } = \sqrt{ 16+16 } = \sqrt{ 32 } = 4\sqrt{ 2 }$$ 
##### For $\vec{V}-\vec{W} = (2,-2) :$
$$|\vec{V}-\vec{W}| = \sqrt{ (2)^2 +(2)^2} = \sqrt{ 4+4 } =\sqrt{ 8 } = 2\sqrt{ 2 }$$

##### Final answer :
1. $\vec{V} + \vec{W} = (4,4)$ , with magnitude $4\sqrt{ 2 }$  .
2. $\vec{V}-\vec{W} = (2,-2)$ , with magnitude $2\sqrt{ 2 }$  .
